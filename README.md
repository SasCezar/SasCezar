# 👋 Hi, I'm Cezar Sas

I'm an **AI Researcher at [IDSIA (USI-SUPSI)](https://www.idsia.ch/)** in Lugano, working on **agentic AI**. I hold a PhD in **AI for Software Engineering** from the University of Groningen and have 8+ years of experience in machine learning for language and code.

🤖 **What I'm working on**
- **Multi-agent systems**: I lead the development of [ant-ai](https://github.com/idea-idsia/ant-ai), an open-source Python framework for multi-agent orchestration (A2A protocol, graph-based workflows, MCP tools). It powers the orchestration service of the HIVEMIND Horizon Europe project.
- **Agentic software engineering**: reverse-engineering design documents from codebases so coding agents can rebuild software that stays closer to the original architecture.
- **Retrieval-augmented generation**: RAG over Italian, Swiss, and EU legal documents to help experts navigate transport regulation.
- **LLM post-training**: adapting open-weight LLMs (e.g., Apertus) to specialized domains with LoRA.

🧠 **Background**: my PhD combined language models and graph neural networks to classify and understand software at the project, package, and file level ([thesis](https://research.rug.nl/en/publications/understanding-software-through-automated-classification-a-taxonom)). Before that, I worked on multilingual QA, semantic parsing, and relation extraction.
