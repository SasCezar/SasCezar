I've spent the last eight years teaching machines to read: first human languages, then source code. These days I'm teaching them to **work together**.

I'm an **AI Researcher at [IDSIA](https://www.idsia.ch/)** in Lugano, where I design multi-agent systems and the infrastructure that makes them reliable. Before that, I did my PhD at the University of Groningen, building models that read a codebase and tell you what it does: a web framework, a game engine, a database. They work on whole projects, single packages and individual files, across 300+ categories.

## Right now

- **Orchestrating agents.** I lead [ant-ai](https://github.com/idea-idsia/ant-ai), our open-source framework for agents that talk over A2A, run graph-based workflows and use MCP tools. It powers the EU-funded HIVEMIND project, where four partners have built on it.
- **Teaching agents to design before they code.** Coding agents jump straight into implementation and rarely think about architecture. I recover the design documents behind 10,000+ real codebases to teach them how software is actually planned. With that grounding, agents build systems whose structure is 17% closer to how a human would have designed them.
- **Making regulation searchable.** A RAG assistant over Italian, Swiss and EU transport law, now in testing with public authorities.
- **Turning generalists into specialists.** Fine-tuning open-weight models like Apertus for narrow domains.
